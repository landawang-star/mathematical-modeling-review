# v1.6.1 审查问题整改追踪

对照 2026-10-16 的 24 项审查发现。本表中的“处理”指当前发布内容不再产生该误导或错误；它**不等于**声称真实论文评审效果已经实证验证。历史样本原件缺失的问题，以撤回效果声称、隔离旧报告和建立复测条件处理。

| 原问题 | 当前处理 | 可核查位置 |
|---|---|---|
| C01 自拟权重/奖项线冒充官方 | 明确区分官方规则与非官方量表，删除奖项阈值 | `SKILL.md`、`references/诊断量表.md` |
| C02 缺结果正确性 | 增加可行性、内部一致性、复现范围检查 | `SKILL.md`“审阅要点” |
| C03 2026 格式细则不实 | 官方强制项、建议项、未规定项分列并附链接 | `references/官方规则与来源.md` |
| C04 漏查 2026 强制项目 | 增加页序、匿名、正文、附录、代码、支撑材料等检查 | 同上 |
| C05 漏 AI 规定 | 增加论文声明和支撑材料详情核查 | 同上 |
| C06 总分算错 | 给唯一公式和确定性脚本；缺项无总分 | `references/诊断量表.md`、`scripts/score.py`、`tests/test_score.py` |
| C07 错误赛事题号 | 旧样本隔离，逐项列错误，不再用于当前宣称 | `validation/README.md`、`archive/` |
| C08 样本计数矛盾 | 撤回旧分母，明确复测须有逐篇清单 | `validation/README.md` |
| C09 “66 篇/类”不可复核 | 删除当前效果宣传，改为如实陈述无盲测集 | `README.md`、`validation/README.md` |
| C10 类型硬规则冲突 | 改为任务、数据、方法、输出指标的描述性记录 | `SKILL.md`“审阅要点” |
| C11 自命名/无文献自动高分 | 创新判断要求差异、机制和验证；缺依据不高分 | `SKILL.md`、`references/诊断量表.md` |
| C12 已知奖项反向调参 | 不用分数推断奖项；复测须冻结规则和独立盲测 | `validation/README.md` |
| C13 输入缺赛题/数据/程序 | 明列材料和可评范围，未提供则标未核查 | `SKILL.md`“开始前” |
| C14 PDF 阈值冲突 | 取消单阈值，检查提取质量并尝试可用 OCR/视觉阅读 | `SKILL.md`“开始前” |
| C15 期刊版缺章节自动豁免 | 原提交版未见时标不可核查 | `SKILL.md`“选用规则” |
| C16 格式问题数机械打分 | 按严重性和适用规则判断；排版未核不称高置信度 | `SKILL.md`、`references/诊断量表.md` |
| C17 全文与抽样混用 | 记录实际覆盖与未读范围，不冒称全文核查 | `SKILL.md`“开始前”及“输出” |
| C18 旧“✅”不能复现 | 隔离历史记录，取消当前实测有效声称；制定复测协议 | `archive/`、`validation/README.md` |
| C19 模拟样例无预期且含伪问题 | 新建纯合成练习与独立期望观察 | `examples/` |
| C20 单文件部署丢 references | 改为完整目录安装并给冒烟核查 | `部署指南.md` |
| C21 “开源”与限制许可冲突 | 依作者选择保留许可，改称源码可读、受限个人使用 | `README.md`、`LICENSE` |
| C22 来源不可追溯 | 2026 官方文件逐项链接；不把自拟规则列官方 | `references/官方规则与来源.md` |
| C23 🅴 与主指令不同步 | 删除 A–E 固定高分触发器，只留统一证据判断 | `SKILL.md` |
| C24 附录可选/八章必含矛盾 | 按适用年份官方规则核查，去掉固定八章分母 | `SKILL.md`、`references/官方规则与来源.md` |

审查报告另列的三个待验证风险同样已纳入设计：跨任务论文不用互斥单类；核心证据不足时保留“未评分”；文献、图表按功能而非数量和类别判断。要量化这些改动是否提升真实论文评审效果，仍须按 [验证状态与复测协议](README.md) 构建合法、独立的论文样本。
