# 验证状态与复测协议

截至 v2.1.0，本仓库提供评分计算单元测试、一份完全合成的行为练习样例，以及[三篇公开获奖论文的探索性试评](真实获奖论文试评_2026-10.md)。其中两篇国一可与组委会名单核对，第三篇国二仅有作者自述。**没有独立盲测集，因此不公布奖项区间判断准确率或“已验证 66 篇”的结论**。`archive/v1-history/` 中的旧报告是历史记录，其中的奖项、题号和样本数量未经统一重新核实。

要在将来发布实际效果指标，先为每篇论文建立可复核样本清单，至少记录：唯一 ID、赛事与年份、赛题编号及官方题目、论文版本（提交版/期刊版/节选）、来源和访问许可、获奖证据链接、文件哈希、是否含赛题/数据/程序、排除原因。**论文数、赛题类别数、复用样本数、全文审阅数分别计数**；不要用“篇/类”混合分母。

实验步骤：

1. 核验赛事、题号和论文身份后，先冻结样本清单及排除规则。双人独立标注有争议的判断，记录分歧及解决理由。
2. 将训练/修规则用样本与独立盲测样本分开，按论文或团队去重。获奖等级只能用于事后分析，不能作为逐篇规则调整目标。
3. 事先固定 Skill 版本、Agent 模型、输入文件、可用工具、提示、评审范围和判定口径；保存完整输出及人工复核记录。
4. 分别报告合规项误报/漏报、结果错误发现率、证据定位正确率、无法核查时的克制程度、奖项区间的混淆情况，以及不同审阅人的一致性。对每项报告分子、分母与不确定性。真实奖项与本 Skill 的诊断分不作阈值拟合。
5. 新规则若由某篇论文启发，该论文进入开发集，不能再作为该规则的独立效果证明。失败样例与成功样例都保留。
