# 数学建模竞赛论文预审助手

一个供 AI 助手使用的 Skill，帮助参赛团队、教师和受聘评委**预审**数学建模论文：核对适用年份的规则，检查模型与结果的证据，指出可定位的问题并给出修改建议。当前版本为 **v2.0.0**。

本项目提供评审辅助，不代表全国大学生数学建模竞赛组委会。正式评阅由组委会及评阅专家依当年赛题细则实施；本项目的诊断分不对应任何奖项。2026 年官方评奖主要关注假设合理性、建模创造性、结果正确性和表述清晰性。[章程](https://www.mcm.edu.cn/upload_cn/node/745/ogFWOgXVc36c27bb3ee3adf21e06f53146b03585.pdf) · [全国奖项评阅工作规范](https://www.mcm.edu.cn/html_cn/node/b1f48689659f0660e80a2d6279d7b37d.html)

## 能做什么

- 对照适用年份的**官方强制规则**检查提交版论文；把写作建议与官方要求分开。
- 检查假设、模型、约束、结果正确性、创造性主张、表达和引用。每项意见指向论文中的证据位置。
- 记录读取范围与尚未提供的赛题、数据、程序或支撑材料；无法核验时明确说明。
- 用户要求时给出**可选的非官方诊断评分**。评分算法和证据要求见 [诊断量表](references/诊断量表.md)。

输入可为 PDF、Word 或 Markdown，实际读取能力取决于所用 AI 助手及其文件工具。PDF 的文本提取不能证明页面排版合规；需要查看页面图像。扫描或文字错乱的文件可能需要 OCR 或可读版本。

## 使用方法

按照 [部署指南](部署指南.md) 将**整个目录**安装为 Skill；只复制 `SKILL.md` 会使参考文件与评分脚本不可用。向助手提供论文，并尽量附上赛题原文、赛事和年份、论文版本、数据/程序/支撑材料及你希望重点检查的部分。例如：

> 请预审这篇 2026 年 CUMCM 参赛论文。附件有赛题、论文 PDF、数据和程序。先核查官方格式与结果可行性，再给按证据排序的修改建议；缺少证据的地方请标“未核查”。

参赛期间使用 AI 工具时，参赛队仍须遵守当年 [AI 工具使用规定](https://www.mcm.edu.cn/html_cn/node/fef94648f2836ab6cc81586f4c38512b.html)，并自行核查 AI 输出。助手的判断不能替代参赛队和评委的责任。

## 项目文件

| 路径 | 用途 |
|---|---|
| [SKILL.md](SKILL.md) | 精简的触发条件、审阅流程和证据边界 |
| [references/官方规则与来源.md](references/官方规则与来源.md) | 2026 年 CUMCM 规则、来源及适用条件 |
| [references/诊断量表.md](references/诊断量表.md) | 可选非官方评分及计算公式 |
| [scripts/score.py](scripts/score.py) | 确定性计算总分；有未评分维度时不输出总分 |
| [examples/](examples/合成练习短稿.md) | 明确标注为合成练习的输入与期望观察 |
| [validation/README.md](validation/README.md) | 验证现状、历史样本问题与未来复测协议 |
| [archive/](archive/README.md) | 带警示的 v1.x 历史资料 |

本版本修正旧版中不实或无法核验的“统一国奖评分标准”“已验证 66 篇”等表述。仓库目前**没有独立盲测集**，因此不公布准确率或获奖预测效果。变更见 [CHANGELOG.md](CHANGELOG.md)。
