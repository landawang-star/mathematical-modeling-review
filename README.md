# Mathematical Modeling Review（数学建模评审）

**把完整赛题和论文交给 AI 助手，得到一份能直接用于修改的 CUMCM 论文评审报告。** 这个 Skill 会逐问检查你的建模有没有真正回答题目，指出论文与建模方案的具体问题，给出五维诊断分，并在证据足够时先告诉你**大概率不获奖、获省奖还是获国奖**，再给出国一、国二、省一、省二或省三的细分预测。报告同时说明预测区间、置信度、可能跨档的原因，以及下一版应该先改哪里。

适用赛事：**高教社杯全国大学生数学建模竞赛（CUMCM）**。可用于赛前预审、修改版复核和赛后复盘。当前版本：**v2.10.0**。这是独立的评审辅助工具，不代表竞赛组委会；奖项预测是非官方经验判断，不保证真实获奖。

## 你会得到什么

| 用户遇到的问题 | 本 Skill 给出的结果 | 你可以据此做什么 |
|---|---|---|
| “我们是不是答偏题了？是不是漏了一问？” | 按题目每一问列出要求、论文回应、缺失的结果、被忽略的约束和证据位置 | 在提交前补齐最影响评阅的任务，而不只是润色摘要 |
| “模型看起来很复杂，结论到底站不站得住？” | 检查假设、量纲、可行性、数值、验证和结论边界；把确定错误、重大待核疑点、局部缺陷分开 | 知道哪些问题必须重算，哪些只需补证据或改说法 |
| “这篇论文大概能拿什么奖？” | 先判**不获奖 / 省奖 / 国奖**，再细分省一/省二/省三或国一/国二 | 获得明确的两阶段结论，同时看清升档、降档风险 |
| “评完之后，具体怎么改？” | 按影响程度排列的论文与提案整改清单：位置、依据、修改动作、验收标准 | 把评语变成可分工执行的修改任务 |
| “修改后真的变好了吗？” | 对照上次清单逐项复核：已解决、仍存在、新出现；证据变化时更新分数和预测 | 避免反复改格式，却没解决核心问题 |

### 五个维度，分别告诉你哪里强、哪里弱

1. **假设与模型合理性（20%）**：目标、变量、题设约束、量纲和假设能否自洽；模型是否真的表示了赛题中的现实过程。
2. **针对性与创造性（25%）**：方法是否击中本题难点，是否给出有作用的设计和对比；不会因为用了热门算法或堆了模型名称就给高分。
3. **结果正确性与可靠性（30%）**：结果是否可行、关键数值是否可信、有没有合适的验证、误差和敏感性分析；“找到一个好解”与“证明全局最优”会区分。
4. **表述清晰性（15%）**：摘要能否说清每问的结果，公式和图表能否复核，正文是否能让评委沿着证据找到结论。
5. **当年规范与引用（10%）**：检查适用年份的强制格式、引用与必要声明；公开展示版与正式提交版分开判断，不把自造的字数或参考文献数量当作获奖门槛。

每维满分 20 分。总分使用确定性规则计算，随后输出**第一阶段获奖层级、第二阶段细分奖级、一个中心预计奖项**和**一个预测区间**。例如：

> 问题与修改：第三问的方案没有证明满足全部题设约束；应补充约束逐项检查表和可复算结果，再重评结果可靠性。
>
> 获奖判断：目前大概率处于省奖范围；细分预计为省一（非官方预测）。预测区间为省二至国二，置信度为中；第三问的约束核验可能改变结论。

这个例子只展示报告样式，不是实际论文的评审结果。预测区间让你知道边界在哪里，具体问题和整改清单告诉你如何提高论文质量。各档分数映射、适用条件和局限见[诊断量表](references/诊断量表.md)。

## 它具体会怎样评你的论文

**先看题，再看文。** Skill 把完整赛题拆成逐问要求：目标、输入数据、限制条件、必须提交的数值、图表或方案。随后定位论文中对应的模型与结果，判断每一问是否形成“题意 → 方法 → 结果 → 验证”的闭环。它特别关注容易影响奖项判断的地方：遗漏关键约束、目标函数与题意不一致、把启发式搜索称为全局最优、只报训练集准确率、数据切分泄漏、单位或边界错误、结果文件与正文不一致。

**问题写得能改。** 报告里的每条重要意见应有论文位置、赛题依据、影响范围、建议动作和完成标准。发现一处局部不足，不会自动把整篇论文判成无奖；没有独立复算的数据，标明“未核查”，不会伪装成已证明错误。若用户另附独立建模提案，会核对提案与论文的目标、假设、模型、结果和验证是否一致；没提供提案，就只评论文中呈现的方案。

**奖项判断写得明确。** 输入满足完整评审条件时，结论直接写“大概率处于省奖范围，细分预计为省一”等两阶段判断，同时给预测区间、理由与置信度。总分靠近档位边界时，报告会指出哪些证据可能让结果跨档。真实奖项还取决于当年同题竞争、赛区推荐和正式评阅；本 Skill 的分数不是官方分数线。

## 3 步开始使用

1. 按[部署指南](部署指南.md)安装**整个 Skill 目录**，保留参考文件和评分脚本；只复制首页文件会丢失完整评审能力。
2. 提供**论文全文 + 对应年份、组别、题号的完整赛题**。题目的附录和关键数据说明也请一并提供；如果有数据、代码、结果文件和独立建模提案，附上可提高核验深度。请说明论文是提交版、展示版还是修订版。
3. 给 AI 助手发送这段指令：

> 请用 Mathematical Modeling Review 评审我这篇高教社杯全国大学生数学建模竞赛论文。附件有完整赛题、论文和可用的支撑材料。请逐问核对赛题，给五维分、非官方总分、预计可获奖项、预测区间、置信度和跨档风险。把论文与建模方案的问题列成按优先级排序的整改清单，逐项写论文位置、题目依据、影响、修改动作和验收标准。未独立复算的内容请明确标出。

只有论文、缺完整题面时，Skill 仍可先做**论文内部初筛**，指出表达、逻辑和可见证据问题；此时不会给完整总分或省奖、国奖预测。扫描版、附件缺失或数据不可读时，报告会说明能评到哪一步。

## 适合哪些用户

- **正在准备 CUMCM 的参赛队**：在提交前发现漏问、错解、约束违反和结果不可复核的问题，并获得可直接分工的修改清单。
- **想知道论文大概能拿什么奖的队伍**：先得到“不获奖/省奖/国奖”判断，再得到省一、省二、省三或国一、国二的细分预测。
- **建模思路很多、但不知道哪里影响奖项的队伍**：把问题分成必须重算、必须补证据、建议修改表达三类，先解决最可能拉低奖项的短板。
- **已经改过一版、想复核是否真正变好的用户**：逐条核对上次整改任务，标记已解决、未解决和新问题，只在证据确实改变时更新分数和奖项预测。
- **赛后复盘的队伍或指导老师**：了解当前论文为什么处在省奖或国奖范围，并将问题转化为下一次训练的检查项。

完整评审最后会直接给出两句结论：**论文或提案哪里有问题、先改什么**；以及**目前大概率是不获奖、省奖还是国奖，最可能的细分奖级是什么**。

## 隐私、适用范围与授权

用户的未公开论文默认只在本地评审，**未经许可不上传第三方网站**。公开论文样本在本仓库仅保留来源链接与评审记录，没有复制原 PDF。处理保密材料时，请同时检查你所用 AI 助手自身的文件和联网设置。

本 Skill 只针对 CUMCM；美赛、研究生建模竞赛等其他赛事不能直接套用此量表和奖项映射。参赛期间使用 AI 工具还须遵守[组委会当年规定](https://www.mcm.edu.cn/html_cn/node/fef94648f2836ab6cc81586f4c38512b.html)。全国评阅参考[竞赛章程](https://www.mcm.edu.cn/upload_cn/node/745/ogFWOgXVc36c27bb3ee3adf21e06f53146b03585.pdf)和[全国奖项评阅工作规范](https://www.mcm.edu.cn/html_cn/node/b1f48689659f0660e80a2d6279d7b37d.html)。
