# 数学建模竞赛论文预审助手

一个供 AI 助手使用的 Skill，帮助参赛团队、教师和评委**预审高教社杯全国大学生数学建模竞赛（CUMCM）论文**：对照完整赛题，指出关键问题，给出多维诊断分，并根据总分给出预计可获奖项和预测区间。当前版本为 **v2.5.0**。不适用于美赛、研究生赛等其他建模赛事。

**[阅读新版公告：评审范围、所需材料和评分边界](公告_评审范围与使用说明.md)**。本项目所说的“整体评审”是对照**整道赛题评审整篇论文**，不表示能评定参赛队的所有条件或准确预测奖项。

需要了解项目已完成的工作、具体能力、v2.0.0—v2.3.0 的改动、公开论文核查证据和当前限制，可阅读[数学建模评审 Skill 能力与建设成果报告](报告_数学建模评审Skill能力与建设成果_2026-10-20.md)。

本项目提供评审辅助，不代表全国大学生数学建模竞赛组委会。正式评阅由组委会及评阅专家依当年赛题细则实施；本项目的分数和区间不是官方获奖线，也不能保证获奖。官方评奖主要关注假设合理性、建模创造性、结果正确性和表述清晰性。[章程](https://www.mcm.edu.cn/upload_cn/node/745/ogFWOgXVc36c27bb3ee3adf21e06f53146b03585.pdf) · [全国奖项评阅工作规范](https://www.mcm.edu.cn/html_cn/node/b1f48689659f0660e80a2d6279d7b37d.html)

## 能做什么

- 逐问对照完整赛题，找出遗漏、约束错误、验证不足和过强结论，并给出可执行修法。
- 完整评审默认给**五维分、加权总分、预计可获奖项、预测区间和置信度**；依据见 [诊断量表](references/诊断量表.md)。
- 对照适用年份的官方强制规则检查提交版；把写作建议、未复算结果与可证实错误分开。
- 对“最小值”“首次发生”“高准确率”等关键结论核查约束、搜索域和验证过程；区分确定错误与待核疑点，说明影响到哪一问。
- 题面不完整时只做论文内部初筛，**不提供完整评分或奖项区间**。

输入可为 PDF、Word 或 Markdown，实际读取能力取决于所用 AI 助手及其文件工具。PDF 的文本提取不能证明页面排版合规；需要查看页面图像。扫描或文字错乱的文件可能需要 OCR 或可读版本。

## 使用方法

按照 [部署指南](部署指南.md) 将**整个目录**安装为 Skill；只复制 `SKILL.md` 会使参考文件与评分脚本不可用。请同时提供**论文全文、完整题面及题目关键附件**，注明年份、组别、题号和论文版本；数据、程序与支撑材料可帮助复算。例如：

> 请预审这篇 2026 年 CUMCM 参赛论文。附件有完整赛题、论文 PDF、数据和程序。请逐问检查，指出主要问题并给出修法，再给五维分、预计可获奖项和预测区间；缺少证据的地方请标“未核查”。

参赛期间使用 AI 工具时，参赛队仍须遵守当年 [AI 工具使用规定](https://www.mcm.edu.cn/html_cn/node/fef94648f2836ab6cc81586f4c38512b.html)，并自行核查 AI 输出。助手的判断不能替代参赛队和评委的责任。
