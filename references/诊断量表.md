# 非官方论文诊断量表

只有用户明确要求数字评分且材料足以支持评分时使用。本量表由项目作者制定，**不是 CUMCM 官方评分细则、获奖概率或国一/国二分界**。优先给证据和修改建议，再给数字。某维证据不足时填“未评分”并说明缺口，不以猜测分代替。

## 五个维度

| 键名 | 诊断维度 | 权重 | 主要证据 |
|---|---|---:|---|
| `assumptions` | 假设与模型合理性 | 20% | 假设依据、目标/约束、量纲、变量与模型之间的一致性 |
| `originality` | 针对性和创造性 | 25% | 对赛题难点的设计、与可核实基线的差异、有效性验证 |
| `correctness` | 结果正确性与可靠性 | 30% | 解的可行性、算术和图表一致性、误差/敏感性、数据程序复现范围 |
| `clarity` | 表述清晰性 | 15% | 摘要、图表、公式、结果解释和局限说明 |
| `compliance` | 适用规范与引用 | 10% | 当年官方强制项、用户提供细则、外部成果的引用标记；未提供材料标未核查 |

每项 0–20 分。0–4：关键部分缺失或可证实的严重错误；5–9：重要缺陷阻碍理解或复核；10–14：完成主要任务但证据、论证或表达有明显空缺；15–17：主要判断有较充分支撑，仍有可修复缺陷；18–20：关键判断充分、可复核且局限交代清楚。**这些档位仅用于同一量表下的诊断一致性，不对应奖项**。特别是创造性，不能因算法名称新、文献少、方法多或未经核实的指标提升自动给高分。

每项必须注明论文位置、判断证据、未核查范围和置信度（高/中/低）。当该维核心判断无法核实时填 `null`，例如仅有论文、无赛题而无法检查是否解决题意，或数学领域超出当前核验能力。低置信度可给带边界的分数，但关键证据缺失时应未评分并请求人工复核。

## 总分

仅当五项均有依据且均为 0–20 数值时计算：

`总分 = Σ(该项分数 ÷ 20 × 该项权重)`，其中权重按百分数 20、25、30、15、10 代入。总分范围 0–100，保留两位小数。不得直接把五项原始分数相加，不得用总分推断获奖等级。用 `python3 scripts/score.py 输入.json` 计算并核对。

例如五项依次为 18、16、17、15、14，则总分为 `18/20×20 + 16/20×25 + 17/20×30 + 15/20×15 + 14/20×10 = 81.75`。这是演算示例，没有论文评审含义。

输入 JSON 示例：

```json
{"assumptions": 18, "originality": 16, "correctness": 17, "clarity": 15, "compliance": 14}
```

如果某项无法评分，把其值设为 `null`；脚本输出 `total: null` 和未评分维度名。不要在报告里补算总分。

## 报告最小结构

1. 基本信息：赛事与年份、论文版本、审阅范围、已读材料、缺失材料。
2. 合规清单：项目、依据链接、适用性、已核查/未核查、证据位置和修正动作。
3. 内容意见：假设、模型与创造性、结果正确性、表达与引用，逐条列证据及反证。
4. 用户要求时附诊断评分：分项、理由、置信度、未评分项与按上述公式计算的可用总分。
5. 修改清单：按可能影响由高到低排列。安全或规则风险、可证实的结果错误优先；一般表达建议随后。

把“官方强制要求”“赛题细则”“本量表评分理由”“写作建议”分别标识，避免读者误把诊断分当作竞赛评委分数。
