# 非官方诊断量表与奖项区间判断

用于 CUMCM 论文的**完整题面 + 可读论文全文**评审。评分是给用户解释强弱和修改优先级的工具，不是组委会标准或获奖概率。数据、代码未提供时仍可评论文中可见的建模和结果证据；对未复算部分降低置信度，并指出何种材料能完成核验。

## 五个维度

| 键名 | 诊断维度 | 权重 | 重点 |
|---|---|---:|---|
| `assumptions` | 假设与模型合理性 | 20% | 题设约束、目标、量纲、变量及模型的一致性 |
| `originality` | 针对性和创造性 | 25% | 对赛题难点的有效设计；不以方法数量、算法名或文献数量计 |
| `correctness` | 结果正确性与可靠性 | 30% | 可行性、关键数值、验证设计、误差与敏感性、结论边界 |
| `clarity` | 表述清晰性 | 15% | 摘要、逐问结果、图表公式解释、复核路径 |
| `compliance` | 当年规范与引用 | 10% | 适用年度的强制要求、必要引用；公开展示版与提交版须区分 |

每维 0–20 分：0–4 为关键部分缺失或可证实的严重错误；5–9 为重要缺陷阻碍核心任务；10–14 为完成主要任务但核心证据或论证存在明显空缺；15–17 为主要结果与模型有较好支撑但仍有可修复缺陷；18–20 为关键判断充分且复核路径清楚。**这些档位不对应省奖或国奖分界**。判分先看题目要求和可见证据，再看加分性的创新与表达。对于公开版缺少支撑文件、未能运行代码、没有做论文未声称的额外验证，应写“未核查”或建议补充，不推定原提交版不存在，也不机械压低所有维度。

每维给出页码/章节证据、扣分缘由及置信度（高/中/低）。扣分须对应[证据核查与问题分级](证据核查与问题分级.md)中明确的影响范围：确定性关键错误会影响相关维度；重大待核疑点主要降低结论置信度，并在论文确实欠缺必要论证时影响相应分数；局部缺陷只处理其所及部分。不要把多个同源疑点重复扣分，或因与另一篇论文的数字不同就判错。

核心页面不可读、缺完整题面而不能判断题意、或严重超出可核验能力时填 `null`，不要用猜测分补齐。能由论文表格、公式和题面判断的部分可给有边界的分数；“没有独立复算”不是所有维度一律未评分的理由。若用户明确要求**只评论文**并声明其他提交条件均合规，基于该前提评分，写明前提及未独立核实项；论文中可见的规范与引用仍可评。不能把该声明当作证明论文核心数值正确。

## 总分

五维均为数值时，`总分 = Σ(维度分 ÷ 20 × 权重百分数)`。使用 `python3 scripts/score.py 输入.json` 计算；任一维为 `null` 则总分为 `null`。总分仅表达本量表下的综合质量，不设 70/80/90 等获奖阈值。

输入示例：

```json
{"assumptions": 16, "originality": 17, "correctness": 15, "clarity": 17, "compliance": 16}
```

## 省奖与国奖竞争区间

在**完整题面和论文**可读、关键结果能作基本一致性检查时，结合逐问覆盖、关键约束、结果可靠性、模型贡献和清晰程度作整体判断：

- **有国奖竞争力**：题目主要任务得到实质回答；核心模型与结果有可追踪证据，未发现足以推翻主要结论的确定性错误；论文能说清针对题目的贡献。可以有局部薄弱、未给全局最优证明、未完成独立复算或仍需修复的表达问题。国一与国二通常不能仅凭论文确定。
- **省奖竞争区间**：完成部分或多数主要任务，但关键问题的建模、验证或结果解释有明显短板；若大幅修复，可能跨入国奖竞争区。省几受赛区差异影响，只有充分证据时给跨档范围。
- **暂不宜判断奖项**：题面不完整、论文缺页/严重不可读、核心结果无法理解，或关键任务只给空泛方法名。若核心数值存在尚未解决、足以跨档的重大疑点，可给**条件性区间**并指出核验后的两种可能，不把待核疑点写成确定失败。若发现致命的题意违背，应先报告并修复后再评区间；不要把“证据不足”写成“确定无奖”。

这是质量判断，不是固定分数换算。先独立判断论文，若其真实奖项已知，**事后**对照并检查是否把普通瑕疵当作自动否决项；不能因已知国奖就倒填高分或忽略实错。与真实奖项不同时，记录证据、版本差异及不确定性，不能单凭一例改出新的硬阈值。只有已核对赛事、身份和官方名单的样本才有可用奖次标签；公开展示、仓库目录和作者自述分别标注，不与官方奖次混用。

## 用获奖论文校准 Skill 时的规则

校准不是把既知奖项当作答案反推分数。每篇样本先完成一份独立评审记录，写清题面版本、论文版本、可读范围、五维理由与质量区间；**完成记录后**才揭示或核对获奖标签。若已知标签在评审前已不可避免地暴露，报告必须标为“回顾性复测”，不能称为盲测。

奖项标签按证据强度分层：

1. 组委会或赛区正式名单，且队员身份、学校和年份能与论文对应；
2. 可核验的赛区获奖证书，且证书上的队员、年份、赛事与论文对应；
3. 学校正式新闻或公示；
4. 作者、仓库或转发页面的自述。

主统计只能使用前两类；第三、四类可保留为候选或案例，不能与主统计混算。论文全文、完整题面或关键附件缺失时，评审结论是“输入不足而弃权”，不得为凑样本数填入总分、奖项区间或错判。统计时分别报告可评分数、弃权数、标签证据等级和每类真实标签的数量；只有同时有国奖、省奖和未获奖样本，且样本在标签揭示前完成评审，才可以讨论准确率、精确率或混淆矩阵。

## 报告顺序

1. 输入与版本、题目逐问覆盖及未核查项。
2. 五维分、加权总分、理由和置信度。
3. 质量区间：支持证据、限制证据、置信度；明确非官方估计。
4. 按影响排序的问题：位置 → 判断依据 → 可能影响 → 修法。

区分“官方强制要求”“题目任务”“论文质量判断”“写作建议”；不要把未经复核的数值或引文写成已验证事实。
