# 证据核查与问题分级

用于把论文反馈落实到赛题任务及结论风险。对照完整题面与题目附件；若缺少会改变建模约束或数值结果的附件，先作内部初筛。

## 逐问证据账

每问记录：题目要求与交付物；论文作答位置；所用数据与假设；报告的数值/方案；约束与边界；论文自带验证；本次实际核验；尚缺证据。题目要求的文件须区分“论文提到文件”“公开仓库可见文件”“原提交文件已核”三种状态。不能从结果表名称推断内容正确，也不能从公开版没附文件推断提交版未交。

对核心数值，优先做四项最小核查：

1. 对齐定义、单位、时间段、对象和精度，确认与题面问的是同一量。
2. 查显式约束、边界及极端情形；若作者缩小碰撞对、时间窗、变量或样本范围，找其排除其余范围的证明或独立扫描。
3. 可行时复算一个代表值、边界点或中间算式；结论若称“首次”“最小”“全局最优”，检查搜索覆盖或误差界。一个不同数值只有在定义与参数一致时才构成反证。
4. 检查验证是否真正检验了所声称的性质：训练拟合不等于预测、求解器收敛不等于全局最优、抽样近似不等于精确分布、敏感性分析不等于所有题设约束均满足。

机器学习题额外核查切分顺序：标准化、缺失值填补、特征筛选、模型调参与集成权重应只从训练部分学习，并在验证折内重做；最终测试集不得参与选模后再用于同一性能声明。摘要写“综合准确率”时回看独立测试集指标、样本量、类别不平衡与重复实验。若论文未写清流程，先列为待核疑点；有明确泄漏路径才称确定错误。

若只能读 OCR、Markdown 镜像或扫描件，发现缺数字、公式错位、页缺失时回看原 PDF 页面；无法回看则标“提取待核”。不同论文的公开版可能经过整理，不能按公开版推定提交时违规。

## 判断等级

| 状态 | 用法 | 对评估的影响 |
|---|---|---|
| 确定性关键错误 | 题面、原页、算式或复算能证明核心任务被错解/核心结果不可行，并说明影响到哪些问 | 直接压低相关维度及区间；其余独立作答仍单独评价 |
| 重大待核疑点 | 有具体反例方向或缺少关键覆盖证明，但尚未证明结论为假 | 要求补扫描、复算或边界证据；降低相应结论与奖项判断置信度，不写成“已经错了” |
| 局部缺陷 | 影响一个推导、表述或次要结果，主要任务仍有支撑 | 定位到对应维度，给修法，不自动否决国奖竞争力 |
| 未核查 | 数据、代码、题目附件、提交件、原 PDF 页面不可得 | 列明所需材料；不能冒充确定错误或据此推算奖次 |

严重程度看**对题目核心结论的实际影响和可修复性**，不由错误数量、算法名或与另一篇论文数值是否相同决定。发现新证据时更新等级及分数，保留前后理由。

## 区间与来源

质量区间与诊断分分开判断。优先报告“国奖竞争力”“省奖竞争区间”“暂无法判断”及置信度；省一、省二、国一、国二只有额外可核的赛区/年度校准证据时才细分。用户已确认的非论文条件可以作为**条件前提**接受，但报告应写清哪些是论文可见证据，哪些来自用户说明。

对公开样本，先确认 PDF 首页及同年题面确为 CUMCM；奖项必须另有官方名单与作者/队伍身份匹配。展示页或 GitHub“优秀论文”目录不能直接作奖次标签。若只有获奖样本、没有省奖和未获奖对照，不报分类准确率、误报率或“已学会国奖标准”。
